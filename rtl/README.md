# RTL (Register Transfer Level)

이 디렉토리에는 ssync 칩간 직렬 동기화 신호 트랜시버의 합성 가능한 Verilog 코드가 포함됩니다.

## 개요

- **언어**: Verilog-2001
- **용도**: ASIC/FPGA 합성 및 구현
- **상태**: 최종 산출물 (Deliverable)

## 핵심 원칙

1. **합성 가능성**
   - `initial` 블록 금지
   - 지연(`#delay`) 금지
   - 합성 불가능한 구조 금지

2. **래치 금지**
   - 모든 `always @(*)` 블록은 모든 경로에서 모든 출력을 할당해야 함
   - 린트 검사에서 자동으로 감지

3. **클록 설계**
   - 생성된 클록 금지
   - 모든 플립플롭은 `pclk` 클록 사용
   - 직렬 비트 레이트는 클록-인에이블 펄스(`ssync_tick_gen`)로 구현

4. **리셋 규칙**
   - 모든 플립플롭: `always @(posedge pclk or negedge presetn)`
   - 비동기 액티브-로우 리셋

5. **출력 레지스터**
   - 모든 모듈 출력은 레지스터화되어야 함

6. **크로스칩 입력 처리**
   - `ss_rx_clk`, `ss_rx_data`는 비동기 처리
   - 사용 전 반드시 더블-플롭으로 동기화
