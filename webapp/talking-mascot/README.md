# 토키(Toki) - 말하는 마스코트 웹앱

텍스트를 입력하면 오리지널 마스코트 캐릭터 "토키"가 음성과 입 모양 애니메이션으로
읽어주는 정적 웹앱입니다. 이 프로젝트는 `serial_sync`(Verilog 시리얼 통신 IP) 저장소와는
무관하며, 별도 웹 프로젝트로 이 디렉토리에만 담겨 있습니다.

## 왜 듀오링고 캐릭터가 아닌가

요청은 듀오링고 팬 사이트의 캐릭터 이미지를 쓰는 것이었지만, 듀오링고의 마스코트는
저작권/상표로 보호되는 캐릭터이고 팬 사이트는 정식 라이선스 배포처가 아닙니다. 그 이미지를
스크래핑해 제품에 넣는 것은 권리 침해 소지가 있어 진행하지 않았습니다. 대신 같은 "친근한
마스코트가 말한다"는 컨셉을 독자적으로 디자인한 캐릭터(토키)로 구현했습니다.

## 왜 SadTalker가 기본 경로가 아닌가

SadTalker는 사진 한 장 + 음성으로 사실적인 말하는 얼굴 영상을 생성하는 딥러닝 모델입니다.
실행하려면 CUDA GPU와 수 GB의 체크포인트 다운로드가 필요한데, 이 프로젝트를 만든 샌드박스
환경에는 GPU가 없고 그런 대용량 모델을 내려받아 상시 구동하기도 적합하지 않습니다. 그래서:

- **기본 앱**은 브라우저에서 SVG 캐릭터 + Web Speech API만으로 실제로 지금 바로 동작합니다.
- **`sadtalker/`** 폴더에 GPU 환경을 가진 사람이 이어서 쓸 수 있는 통합 스크립트와 설치
  가이드를 남겨두었습니다 (연결만 되어 있고, 이 환경에서 실행/검증하지는 않았습니다).

같은 이유로 클라우드 TTS(예: edge-tts가 쓰는 Microsoft 엔드포인트)도 이 샌드박스의
아웃바운드 정책에서 막혀 있어(403) 서버 쪽에서 호출할 수 없었습니다. 그래서 서버 없이
브라우저 내장 TTS(Web Speech API)를 사용하도록 설계했습니다.

## 실행 방법

빌드나 서버가 필요 없습니다. 정적 파일 3개(`index.html`, `style.css`, `app.js`)뿐입니다.

```sh
cd webapp/talking-mascot
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 바로 열어도 됩니다 (Chrome/Edge 권장).

## 동작 방식

- 텍스트를 입력하고 "말하기"를 누르면 `window.speechSynthesis`로 음성을 재생합니다.
- 목소리 드롭다운은 브라우저/OS에 설치된 음성 목록(한국어 음성 우선 정렬)을 보여줍니다.
  설치된 한국어 음성이 없으면 브라우저 기본 음성으로 재생됩니다.
- 말하는 동안 SVG 캐릭터의 입이 일정 간격 + 단어 경계(`onboundary`) 이벤트에 맞춰
  열리고 닫히며, 눈은 별도로 주기적으로 깜빡입니다.
- 이 브라우저가 음성 합성을 지원하지 않으면(구형 브라우저 등) 음성 없이 애니메이션만
  텍스트 길이에 비례한 시간 동안 재생됩니다.

## 알려진 한계

- Web Speech API 음성 품질/언어 지원은 사용자의 OS와 브라우저에 설치된 음성 엔진에
  달려 있습니다 (서버가 아니라 클라이언트 로컬에서 합성됩니다).
- 입 모양은 실제 립싱크가 아니라 음성 재생 타이밍에 맞춘 근사 애니메이션입니다.
  진짜 사진 기반 립싱크 영상이 필요하면 `sadtalker/` 경로를 참고하세요.
